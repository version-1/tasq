# Code Go

Before working on Go code:

1. Read `../code-general/SKILL.md`.
2. Read the relevant files under `./references/`, starting with `./references/lang.md` when it exists.
3. Follow the Go-specific judgment principles documented in those reference files.

Keep Go changes idiomatic, small, testable, and aligned with the package boundaries already present in the repository.
