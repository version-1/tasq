# Web UI Color Pallete

The Web UI color tokens are defined in `web/app/globals.css`.

| Token | Hex | Usage |
| --- | --- | --- |
| `--bg` | `#f6f7f9` | App background. |
| `--surface` | `#ffffff` | Primary panel, card, and control surface. |
| `--surface-strong` | `#101820` | Strong surface for high-emphasis controls. |
| `--border` | `#d8dee7` | Borders and dividers. |
| `--text` | `#17202a` | Primary text. |
| `--muted` | `#667085` | Secondary text and low-emphasis metadata. |
| `--accent` | `#1769aa` | Existing accent for active navigation and informational emphasis. |
| `--accent-color` | `#7C3AED` | Browser `accent-color` source and primary purple accent token. |
| `--glow-color` | `#A78BFA` | Glow and soft highlight effects. |
| `--accent-strong` | `#0f4c81` | Strong accent text and emphasized status values. |
| `--danger` | `#b42318` | Error and destructive-state text. |
| `--warning` | `#a15c07` | Warning and high-priority state text. |
| `--ok` | `#087443` | Success and healthy-state text. |
| `--primary-black` | `#0A0A0A` | Primary black for high-contrast UI elements. |
| `--dark-gray` | `#1A1A1A` | Dark neutral surface or text. |
| `--medium-gray` | `#666666` | Medium neutral text and metadata. |
| `--light-gray` | `#E5E5E5` | Light neutral borders and separators. |
| `--extra-light-gray` | `#F5F5F5` | Extra-light neutral backgrounds. |
| `--white` | `#FFFFFF` | White surfaces and reversed text. |
