# Code React

Before working on React code:

1. Read `../code-general/SKILL.md`.
2. Read `../code-ts/references/lang.md` for the shared TypeScript guidance used by React and TSX code.
3. Read the relevant files under `./references/`, starting with `./references/lang.md` when it exists.
4. Follow the React-specific judgment principles documented in those reference files.

Keep React changes component-focused, accessible, predictable in state ownership, and consistent with the existing routing, styling, and test patterns.
