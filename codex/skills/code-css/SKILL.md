# Code CSS

Before working on CSS or stylesheet code:

1. Read `../code-general/SKILL.md`.
2. Read the relevant files under `./references/`, starting with `./references/lang.md` when it exists.
3. Follow the CSS-specific judgment principles documented in those reference files.

Keep styling changes scoped, responsive, accessible, and consistent with the existing design system and cascade boundaries.
