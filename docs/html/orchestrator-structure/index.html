The orchestrator reads issue data, prepares workspace/run metadata, and records runner diagnostics in its local runstore.

Runner Protocol

flowchart TD
  A[Validate task: workspace, command, timeouts] --> B[Render prompt template]
  B --> C[Start bash -lc codex app-server]
  C --> D[JSON-RPC initialize]
  D --> E[initialized notification]
  E --> F[thread/start]
  F --> G[turn/start first prompt]
  G --> H{turn/completed?}
  H -- succeeded --> I{continuation enabled and turns remain?}
  I -- yes --> J[turn/start continuation guidance]
  J --> H
  I -- no --> K[Result succeeded]
  H -- failed/error --> L[Result failed with error text]
  C --> M[stderr scanner records runner event]
Task contract Issue, RunID, Workspace, prompt template, max turns, continuation flag, command, read/turn timeouts, and OnEvent.
Result contract Status is mapped back to run status. Error is persisted on the run record when non-empty.
Event contract Runner events store event type, message, optional payload JSON, run id, and occurrence time for operator visibility.

Risks / Open Questions

Concurrency semantics max_concurrent_agents is parsed from workflow config, but current orchestration does not expose a durable cross-process coordination table. Verify expected multi-run throughput before relying on configured concurrency.
Process restart recovery Durable runs exist, but active runtime coordination is not restored by replaying prior run rows.
Prompt rendering Template substitution is intentionally small and covers issue id/title/description and attempt. More fields require explicit contract changes.
Runner observability Runner events and setup failures are persisted; operator-facing surfacing depends on consumers reading SQLite or future UI/API work.
Filesystem cost Workspace population walks and copies the source tree while skipping .git, .worktrees, and node_modules. Large repos may still be expensive.
External process contract CodexRunner depends on JSON-RPC shapes from codex app-server; protocol drift needs focused integration coverage.
