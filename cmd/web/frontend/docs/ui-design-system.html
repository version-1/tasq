Foundations

Principles Before Tokens

Tasq is a quiet, dense, operational UI. The design system should optimize scanning, comparison, repeated action, and handoff clarity before decoration.

Product personality

  • Quiet and utilitarian product screens.
  • Dense but organized information layout.
  • Systematic reuse before expressive one-offs.
  • State-forward status and priority presentation.

Interaction principles

  • Controls must look interactive before hover.
  • Repeated workflows should avoid layout shift.
  • State uses text plus icon, dot, border, or position.
  • Keyboard and screen-reader behavior is contractual.

Anti-patterns

  • Ad hoc hex values when a token exists.
  • Feature-local primitives that duplicate shared UI.
  • One-off spacing values for local tuning.
  • Decorative cards, gradients, and oversized heroes in tools.
